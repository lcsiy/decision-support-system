## 6. 修复附注（2026-08-20 晚间已修复）

### 根因定位（基于 14:37 真实数据复核）

报告 2.2/2.3 现象的根因比"字段漂移"更精确：

1. **verdict 层已修复**：三只持仓 bull=HOLD / bear=CONFIRM_SELL / risk=SELL 解析全部正确
   （此前的别名映射 + json_mode 改造生效）。
2. **列表字段全空（真正缺口）**：LLM 把论证写进 `reasoning` 纯文本（"1) 2) 3)" 枚举），
   **不填** `hold_reasons` / `bearish_signals` / `decisive_factors` 结构化列表
   → 报告显示 factors=[]、理由不可审计。
3. **debate_winner 全 TIE**：LLM 未输出 winner 字段（或输出未映射的键）→ 默认 "TIE"，
   即使 risk 文本明说"空头论点更强"。
4. **浮点尾差**：`adjusted_confidence=57.99999999999999`（未 round）。

### 修复内容（dss/llm_analyst/sell_side.py）

| 问题 | 修复 |
|---|---|
| 列表字段全空 | 新增 `_extract_reasoning_items()`：从 reasoning 枚举文本提取列表项
  （"1) xxx 2) yyy" / "① ②" / "- 项目符号"，编号 ≤20、"." 后须跟空白，
  避免 "-6.20%"、"(22.51)" 被误切）；hold_reasons/bearish_signals/
  decisive_factors 为空时兜底填充 |
| debate_winner 全 TIE | 新增 `_infer_debate_winner()`：① 风控文本线索（"空头论点更强"/
  "止损纪律应优先执行"/"支持卖出"等 → BEAR）② 置信度差 ≥0.15 → 高置信方
  ③ verdict 辅助 ④ 否则 TIE |
| 浮点尾差 | `adjusted_confidence = round(conf * 100, 1)` |
